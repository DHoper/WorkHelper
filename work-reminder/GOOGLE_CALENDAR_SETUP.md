# Google Calendar 整合使用說明

本文檔說明如何在 WorkHelper 應用程式中設定 Google Calendar 整合功能。

## 功能簡介

Google Calendar 整合功能可以：
- 自動獲取您的 Google 日曆事件
- 根據關鍵字過濾會議（例如：只提醒包含"討論"、"會議"等關鍵字的事件）
- 在會議開始前自動發送桌面通知（可設定提前 5-60 分鐘）
- 支援多個日曆（包含您加入的其他人創建的日曆）

## 設定步驟

### 步驟 1: 建立 Google Cloud 專案並啟用 Calendar API

1. 前往 [Google Cloud Console](https://console.cloud.google.com/)
2. 點擊「建立專案」或選擇現有專案
3. 在側邊欄中，選擇「API 和服務」 > 「資料庫」
4. 搜尋「Google Calendar API」並點擊「啟用」

### 步驟 2: 建立 OAuth 2.0 憑證

1. 在 Google Cloud Console 中，前往「API 和服務」 > 「憑證」
2. 點擊「建立憑證」 > 「OAuth 用戶端 ID」
3. 如果這是第一次建立，您需要先設定「OAuth 同意畫面」：
   - 選擇「外部」使用者類型
   - 填寫應用程式名稱（例如：「WorkHelper」）
   - 填寫使用者支援電子郵件
   - 在「範圍」部分，添加 `../auth/calendar.readonly` 範圍
   - 在「測試使用者」中添加您的 Google 帳號
   - 儲存並繼續
4. 回到「憑證」頁面，再次點擊「建立憑證」 > 「OAuth 用戶端 ID」
5. 選擇應用程式類型：
   - 如果是桌面應用：選擇「電腦版應用程式」
   - 應用程式名稱：輸入「WorkHelper」
6. 點擊「建立」
7. 記下顯示的「用戶端 ID」和「用戶端密鑰」（稍後會用到）

### 步驟 3: 在 WorkHelper 中設定憑證

1. 啟動 WorkHelper 應用程式
2. 點擊側邊欄的「日曆提醒」圖示（日曆圖示）
3. 點擊右上角的「設定」按鈕
4. 在設定面板中：
   - **Client ID**: 貼上從 Google Cloud Console 複製的「用戶端 ID」
   - **Client Secret**: 貼上「用戶端密鑰」
5. 點擊「儲存設定」

### 步驟 4: 授權 Google 帳號

1. 在日曆提醒頁面，點擊「開始連結」按鈕
2. 系統會自動開啟瀏覽器，顯示 Google 授權頁面
3. 選擇您的 Google 帳號
4. 在權限請求頁面，點擊「允許」授予日曆讀取權限
5. 授權完成後，Google 會顯示一組「授權碼」
6. 複製授權碼，回到 WorkHelper
7. 將授權碼貼到輸入框中
8. 點擊「完成連結」

### 步驟 5: 設定關鍵字過濾（可選）

1. 連結成功後，您可以在「關鍵字過濾」區域添加關鍵字
2. 例如：「會議」、「討論」、「評審」、「站立會」
3. 系統只會提醒包含這些關鍵字的事件
4. 如果不設定關鍵字，則會提醒所有事件

### 步驟 6: 設定提醒時間

1. 在「提醒設定」區域，選擇提前提醒的時間
2. 可選擇：5、10、15、30 或 60 分鐘
3. 預設為提前 15 分鐘提醒

### 步驟 7: 開始監控

1. 點擊右上角的「開始監控」按鈕
2. 系統會每 5 分鐘自動檢查一次即將到來的會議
3. 符合條件的會議會在設定的時間前發送桌面通知

## 使用說明

### 查看即將到來的會議

- 連結 Google 日曆後，應用程式會自動顯示未來 24 小時的會議
- 點擊「重新整理」按鈕可以手動更新事件列表

### 會議顯示資訊

每個會議會顯示：
- 日期和時間
- 會議標題
- 地點（如果有）
- 描述（如果有）
- 狀態指示器（綠色=已確認，黃色=暫定，灰色=已取消）

### 桌面通知

當會議即將開始時（根據您設定的提前時間），您會收到：
- 桌面通知，顯示會議名稱和剩餘時間
- 點擊通知可以快速開啟 WorkHelper 應用程式

### 管理關鍵字

- **新增關鍵字**: 在輸入框中輸入關鍵字，按 Enter 或點擊「+」按鈕
- **移除關鍵字**: 點擊關鍵字標籤上的「×」按鈕
- **關鍵字匹配**: 系統會檢查會議標題和描述是否包含關鍵字（不區分大小寫）

### 停止監控

- 點擊「停止監控」按鈕可以暫停自動檢查
- 停止後不會收到新的提醒，但可以隨時重新開始

### 登出

- 點擊「登出」按鈕會清除授權資訊
- 登出後需要重新完成授權流程

## 常見問題

### Q: 授權碼在哪裡找？
A: 完成 Google 授權流程後，瀏覽器會顯示一組授權碼。複製整個授權碼（通常是一長串字元），貼到 WorkHelper 的輸入框中。

### Q: 可以使用多個 Google 帳號嗎？
A: 目前一次只能連結一個 Google 帳號。如需切換帳號，請先登出，然後重新授權。

### Q: 關鍵字過濾如何運作？
A: 系統會檢查會議的「標題」和「描述」欄位，只要其中包含任一關鍵字（不區分大小寫）就會提醒。例如，設定「討論」關鍵字，則「項目討論會」、「技術討論」都會被提醒。

### Q: 為什麼看不到某些日曆的事件？
A: 請確認：
1. 在 Google Calendar 網頁版中，該日曆是否已啟用並可見
2. 您的 Google 帳號是否有該日曆的查看權限
3. 重新整理事件列表

### Q: 可以修改提醒聲音嗎？
A: 目前使用系統預設的通知聲音。未來版本可能會支援自訂。

### Q: 監控多久檢查一次？
A: 系統每 5 分鐘自動檢查一次即將到來的會議。這個頻率足以確保您不會錯過任何提醒。

### Q: 授權 Token 會過期嗎？
A: Google OAuth Token 會自動更新，通常不需要重新授權。如果遇到認證失敗，請嘗試登出並重新授權。

### Q: 包含團隊成員創建的會議嗎？
A: 是的！只要該會議出現在您的 Google 日曆中（無論是您創建的還是其他人邀請您的），都會被檢測到。關鍵字過濾同樣適用於這些會議。

## 安全性說明

- **資料存儲**: OAuth Token 存儲在您的本機電腦上（使用者資料目錄）
- **權限範圍**: 應用程式僅請求「讀取日曆」權限，無法修改或刪除您的日曆事件
- **資料傳輸**: 所有資料傳輸都使用 HTTPS 加密
- **隱私**: 您的日曆資料僅在本機處理，不會發送到第三方伺服器

## 技術支援

如果遇到任何問題：
1. 檢查 Google Cloud Console 中 Calendar API 是否已啟用
2. 確認 OAuth 憑證設定正確
3. 嘗試登出並重新授權
4. 檢查應用程式日誌（位於使用者資料目錄的 logs 資料夾）

---

**提示**: 第一次設定可能需要 5-10 分鐘，但之後就可以自動運行，無需再次設定。
